 Dinu Cake Shop - Web Development Project 

Exciting to share my latest web design project — "Dinu Cake Shop", a clean, user-friendly, and responsive cake bakery website concept built as part of my practical learning journey in Web Development!

# Key Features & Pages:
  *Home Page:* Visually appealing hero banner showcasing signature products and a warm welcome.
  *Gallery Page:* Interactive grid layout displaying a variety of delicious cakes.
  *About Us Page:* Brand story and commitment to quality ingredients.
  *Contact Page:* Functional contact form along with business email and phone details.

# Tech Stack Used:
  * HTML5 & CSS3
  * Responsive Web Layout Design
  * Clean Navigation UI
